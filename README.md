# 饮食人格测试 | What's Your Diet Planet?

**An Interactive Game About Dietary Habits and Health Awareness**

一款以日常饮食行为为切入点的公共健康交互游戏，通过游戏化叙事、饮食选择与星球生成机制，将抽象的健康风险信息转化为直观、有趣的交互体验。

---

## About / 项目简介

如果每个人的饮食习惯都是一颗星球，那么你的星球会是什么模样？

《饮食人格测试》以食管癌相关饮食风险因素为研究背景，通过游戏化的方式探索日常饮食行为与健康之间的联系。

玩家将在不同生活场景中做出饮食选择，逐渐形成独特的饮食画像，并最终生成属于自己的「饮食星球」。

项目旨在以轻松、有趣的交互体验，降低公共健康信息的理解门槛，激发玩家对自身饮食习惯的关注与反思。

## Gameplay / 游戏玩法

游戏由三个连续的饮食场景构成：

- **ACT 01 · 早餐 Breakfast** — 探索日常早餐偏好。
- **ACT 02 · 午餐 Lunch** — 体验不同食物与饮食行为的选择。
- **ACT 03 · 火锅 Hot Pot** — 在社交聚餐情境中探索饮食习惯。

完成游戏后，系统将根据玩家的选择生成个性化「饮食星球」，并提供相关饮食行为与健康风险信息反馈。

## Design / 设计理念

**From Dietary Habits to a Personal Planet.**

以「饮食星球」作为视觉隐喻，将抽象的饮食行为与健康信息转译为可感知的视觉反馈。

通过游戏化叙事与参与式交互，让健康知识不再只是被动接收的信息，而成为一次主动探索与自我观察的过程。
